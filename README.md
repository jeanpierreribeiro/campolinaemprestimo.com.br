# campolinaemprestimo.com.br

Landing page oficial da **Campolina Consignado** — Soluções de crédito consignado para aposentados, pensionistas e servidores públicos, e antecipação do FGTS.

## 🚀 Tecnologias

- **HTML5 & CSS3** (Tailwind CSS compilado)
- **JavaScript Moderno** (Accordion interativo, navegação e scroll suave)
- **React + TanStack Router + Vite** (Código fonte para desenvolvimento)
- **Otimizado para Vercel** com `cleanUrls: true`

## 📁 Estrutura do Projeto

- `index.html`: Landing page principal completa e autônoma.
- `politica-de-privacidade.html`: Página com a Política de Privacidade e conformidade LGPD.
- `assets/`: Estilos CSS, scripts e imagens oficiais (`campolina-logo-transparente.png`, etc.).
- `src/`: Código-fonte completo em React/TypeScript com componentes Shadcn UI.
- `vercel.json`: Configuração de deploy estático na Vercel.

## 💻 Desenvolvimento Local

Para rodar em modo estático:
Basta abrir o arquivo `index.html` em qualquer navegador ou usar um servidor local:
```sh
npx serve .
```

Para rodar o ambiente de desenvolvimento React:
```sh
npm install
npm run dev
```
